# 정확도 측정 세트

대표 검색어 5개에서 당근·번개장터 상위 각 20개(검색어당 40개)를 저장합니다. 한 마켓의 결과가 부족하면 다른 마켓에서 부족한 수를 채웁니다.
`npx tsx scripts/capture-labels.ts`로 새로 수집할 수 있습니다. 재실행하면 현재 세트를 덮어씁니다.

각 매물의 `relevant`(동일 상품), `advertisement`(광고·매입), `normal`(제외하면 안 되는 정상 판매 매물)을 사람이 확인하고 true/false로 입력한 뒤 `reviewed`를 true로 설정합니다.
용량 선택 토큰과 액세서리 배제어는 사용자 결정대로 TRD v0.2를 따릅니다.

`npm run accuracy`로 관련성 일치율, 광고 제거율, 정상 매물 오제거율을 계산합니다.
미검토 라벨은 평가하지 않습니다. 정상·광고 표본이 없으면 해당 지표는 평가 불가로 표시합니다.
자동 생성한 판정을 정답 라벨로 취급하지 않습니다.
